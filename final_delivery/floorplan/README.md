# Floorplan Submission Package

Expected academic/lab deliverables:

1. `floorplan.tcl` — copied from `scripts/floorplan/01_floorplan.tcl` by `make final`.
2. `reports/` — floorplan check/QoR/utilization/timing reports.
3. `screenshot/` — place the actual ICC2 GUI screenshot here. The flow does not fabricate a screenshot; use the saved `mips_16/floorplan` block, Zoom Fit, show die/core/cells/pins (and PG only if already built), and save the image.
